# Phase 4: Browser / WebAssembly Client, Transports, and Relay

Branch: `phase4-web` (from `main` `5af83dd`).
Spec: `docs/superpowers/specs/2026-11-20-cs16-rs-master-plan-design.md` (§4, §6 Phase 4, §8 Risk R4).

## Architecture

1. **`cs-vfs`**: `VfsBackend` trait (`list_paths`, `contains`, `read_bytes`), `CachingBackend<B>` with byte-budget eviction, and `Vfs::from_layered_memory` preserving GoldSrc layer priority (`mods/*` > `cstrike_downloads` > `cstrike_hd` > `cstrike` > `valve` > `platform`) for browser folder pickers and drag-and-drop.
2. **`cs-platform`**: `WebClock` (`performance.now()` on `wasm32`) and `ConfigStorage` (`MemoryStorage`, `NativeFileStorage`, `WebLocalStorage`).
3. **`cs-transport`**: `PeerAddr::Web(u32)`, `ChannelTransport`/`ChannelHandle`, `MultiTransport`, and a zero-`unsafe` RFC 6455 WebSocket + HTTP/1.1 static server (`ws_proto` + `ws_native`).
4. **`cs-relay`**: Hardened WS-to-UDP Protocol 48 proxy enforcing explicit `--allow` target allowlists, per-IP and total session caps, deterministic token-bucket rate limits, idle timeouts, and Protocol 48 OOB/NetChan packet validation.
5. **`cs-server`**: `--web-port`, `--web-dir`, and `--relay-allow` flags multiplexing UDP and WebSocket clients on one 100 Hz `Server<G>`, serving `web/` assets and optional `/relay`.
6. **`cs-client`**: Exposes `wasm32`-clean library (`camera`, `hudtext`, `input`, `render`, `ui`, `view`) supporting WebGPU and WebGL2 downlevel limits (2048x2048 lightmap atlas fits cleanly).
7. **`cs-web` + `web/` + `xtask web-build`**: Pure safe-Rust (`unsafe_code = "forbid"`, no `#[wasm_bindgen]` proc-macros) `wasm32` entrypoint registering `window.cs16Web`, paired with ES modules for `showDirectoryPicker` / `webkitdirectory` / drag-drop + IndexedDB caching, WebTransport datagrams + WebSocket fallback, Pointer Lock (`unadjustedMovement`) + Fullscreen + Gamepad + Touch, gesture-unlocked Web Audio, and installable PWA offline bots.
8. **Verification**: `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`, `wasm32-unknown-unknown` checks across library crates + `cs-relay --lib` + `cs-client --lib` + `cs-web`, `cargo xtask parity`, `node --check`, live `cs-server --web-port` HTTP/relay smoke test, and local fast-forward merge to `main`.
