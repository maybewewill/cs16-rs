## Part B: the owner's checks

👤 Run these on the original Counter-Strike 1.6 client (Steam, build 10210). Start the server from the repository root:

```powershell
cargo run -p cs-server -- --proto48 --map de_dust2 --port 27015
```

Switch maps with `changelevel cs_office` or `changelevel as_oilrig` in the server console. Add bots with `bot_add_t`, `bot_add_ct`, `bot_quota <n>` (or `--bots <n>`), and kick them with `bot_kick` (`bot_kick t` / `bot_kick ct`). For tests needing two humans or a passive victim, join a second original client or run:

```powershell
cargo run -p cs-probe -- --connect 127.0.0.1:27015 --seconds 600 --cmd "jointeam 2" --cmd "joinclass 1"
```
